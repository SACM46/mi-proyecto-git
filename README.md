# Flujo básico de trabajo con Git y GitHub desde la terminal

Este proyecto documenta el proceso paso a paso para crear y subir un proyecto a GitHub utilizando Git desde la terminal. Se incluye la creación de un archivo `index.html`, configuración del repositorio, conexión con GitHub y manejo de ramas.

## 1. Crear carpeta de proyecto y archivo `index.html`

```bash
mkdir mi-proyecto-git
cd mi-proyecto-git
touch index.html
